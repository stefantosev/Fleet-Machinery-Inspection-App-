# Fleet & Machinery Inspection App 

A responsive, enterprise-grade mobile application built using **Microsoft Power Platform** for managing fleet equipment and automating inspection workflows.

## Project Overview
The **Fleet & Machinery Inspection App** allows field inspectors and organization administrators to manage mobile assets, perform real-time equipment safety inspections, track operational status, and automatically notify personnel regarding critical maintenance failures.

The application features a fully responsive UI with a custom **Dark / Off-Black & Wheat** design system, secure multi-table CRUD operations, dynamic status indicators, and multi-channel automated workflows via **Power Automate**.

## Architecture & Tech Stack

- **Power Apps (Canvas App):** Mobile interface with dynamic filtering, pop-up modal interactions, and status indicators.
- **SharePonint:** Enterprise cloud datastore ('FleetVehicles' &'InspectionLogs').
- **Power Automate:** Automated notifications, instant alert triggers, and scheduled reporting.
